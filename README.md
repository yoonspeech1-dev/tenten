# 웰컴텐텐 👶🏻

텐텐이를 위한 출산 준비 체크리스트 앱

## 주요 기능

### 📋 카테고리 관리
- 자유롭게 카테고리 생성 (텐텐준비물, 출산준비물, 조리원준비물 등)
- 두 가지 유형 선택 가능:
  - **체크리스트형**: 할 일 관리
  - **구매리스트형**: 제품 구매 및 예산 관리

### ✅ 체크리스트 기능
- 투두리스트 형태로 할 일 추가
- 완료 체크 시 취소선 표시
- 진행 상황 한눈에 확인

### 🛒 구매리스트 기능
- 제품명, 가격 입력
- 실구매가 설정 (정가와 동일 or 직접 입력)
- 구매 링크 저장 및 바로가기
- 총 합계 금액 자동 계산

### 💾 데이터 저장
- 브라우저 로컬스토리지에 자동 저장
- 앱을 다시 열어도 데이터 유지

### 📱 모바일 최적화
- 모바일 우선 반응형 디자인
- 터치 친화적 UI
- 부드러운 애니메이션

## 사용 방법

### 1. 앱 실행
브라우저에서 `index.html` 파일을 엽니다.

### 2. 카테고리 만들기
1. "새 카테고리 만들기" 버튼 클릭
2. 카테고리 이름 입력
3. 유형 선택 (체크리스트 or 구매리스트)
4. "만들기" 버튼 클릭

### 3. 항목 추가하기
1. 카테고리 카드 클릭
2. "항목 추가" 버튼 클릭
3. 정보 입력
4. "추가" 버튼 클릭

### 4. 체크리스트 완료하기
- 체크박스 클릭으로 완료 표시

### 5. 구매 링크 활용
- 🔗 구매링크 클릭하면 외부 사이트로 이동

## 기술 스택

- HTML5
- CSS3 (파스텔 컬러, 모바일 최적화)
- Vanilla JavaScript
- LocalStorage

- 여아를 위한 부드러운 색감
- 귀여운 아기 이모지 👶🏻
- 카드형 레이아웃
- 부드러운 애니메이션
